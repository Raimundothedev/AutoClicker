# Auto Clicker

A simple auto-clicker built with **Python** and **CustomTkinter**.

## Features

* Configurable hotkey
* Adjustable click interval
* Left and right mouse buttons
* Simple graphical interface

## Requirements

* Python 3.13+
* CustomTkinter
* PyAutoGUI
* Keyboard

## Usage

```bash
pip install -r requirements.txt
python main.py
```

> A personal project created for learning and practicing Python.
